# Automotive Structure Lab — Beta 1.0

Piattaforma statica per confrontare Ferrari GTC4Lusso, Aston Martin Vanquish Zagato Shooting Brake, Porsche Panamera Sport Turismo, Aston Martin DB12 e McLaren GT.

## Funzionalità
- Anteprime 3D di carrozzeria esterne tramite Sketchfab per le prime quattro auto.
- Link alla collezione McLaren GT, in attesa di identificare un modello incorporabile verificato.
- Schede Scocca e Telaio con documentazione pubblica e obiettivi dello studio.
- Layout responsive per computer, tablet e smartphone.
- Pulsante per aprire il modello su Sketchfab nel caso l'embed sia bloccato.

## Limiti tecnici
Non contiene file CAD originali dei telai e non ricostruisce strutture di cui non è nota la geometria. I contenuti di terzi restano sui rispettivi siti e soggetti alle condizioni degli autori. Una mesh di visualizzazione non è un modello da produzione, FEM o verifica di crash.
